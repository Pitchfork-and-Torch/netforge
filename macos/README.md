# NetForge for macOS

**Automatic network performance tuning and optional hardening for macOS 12+.**

Part of the [NetForge monorepo](https://github.com/Pitchfork-and-Torch/netforge). See [../SUITE.md](../SUITE.md).

## Quick install

```bash
git clone https://github.com/Pitchfork-and-Torch/netforge.git
cd netforge/macos
./src/netforge-status.sh
sudo ./src/install-network-auto.sh
```

Bootstrap:

```bash
curl -fsSL https://raw.githubusercontent.com/Pitchfork-and-Torch/netforge/main/macos/install.sh | sudo bash
```
